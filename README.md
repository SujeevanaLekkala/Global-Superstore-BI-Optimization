# Global Superstore: Profitability & Supply Chain Optimization

## 📖 Overview
This project delivers an end-to-end Business Intelligence (BI) solution for **Global Superstore**, transitioning from basic reporting to advanced operational intelligence. The primary goal was to centralize disconnected sales, shipping, and customer data into a unified analytical platform to protect margins and scale efficiently.

## 🎯 Project Objectives
* **Centralization:** Developed a single source of truth by integrating disparate Sales, Shipping, and Product datasets.
* **Optimization:** Identified profit drivers and operational inefficiencies, specifically targeting rising shipping costs.
* **Architecture:** Implemented a robust **Star Schema** data model and a fully integrated ETL pipeline.
* **Predictive Insights:** Enabled data-driven decision-making through interactive dashboards and predictive forecasting.

## 🛠️ Technical Architecture
* **Data Pipeline:** End-to-end flow encompassing Data Acquisition, ETL Processing, and Data Warehousing.
* **Data Modeling:** Robust Star Schema design for optimized query performance and analytical depth.
* **Analytical Suite:** Built using **Power BI**, utilizing DAX for complex measures and UI/UX best practices for stakeholder dashboards.
* **Predictive Modeling:** Integrated **XGBoost** to forecast profit margins and shipping costs with high precision.

## 📊 Key Performance Indicators (KPIs)
The dashboard provides real-time tracking and deep-dives into:
* **Financials:** Net Profit Margin, Sales PY (Prior Year), and Net Profit.
* **Logistics:** Average Shipping Cost per Order and On-Time Shipment Rate (Currently **75.8%**).
* **Operational:** Product-level "Cost-to-Serve" and Profit-Wasting analysis via Decomposition Trees.

## 🚀 Key Insights & Business Impact
* **Behavioral Segmentation:** Leveraged RFM Analysis to discover that 'Champions' drive **64%** of total revenue.
* **Profitability Levers:** Identified specific "Profit-Wasting" products and regional shipping cost spikes through root-cause analysis.
* **Strategic Alignment:** Provided actionable insights for Sales, Operations, Marketing, and Finance stakeholders.
